# Documentacao Academica

Esta pasta contem o relatorio do projeto Barber SaaS, desenvolvido para a disciplina de Projeto do curso de ADS da Univali.

## Conteudo

Adicione aqui o arquivo PDF do relatorio:

- `relatorio-etapa1.pdf` - Relatorio da Etapa 1

## Como adicionar o PDF

Coloque o arquivo `.pdf` nesta pasta e faca o commit:

```bash
git add docs/relatorio-etapa1.pdf
git commit -m "docs: adicionar relatorio etapa 1"
git push
```
